Desafio #611

Endereços do kernel - Um pouco de aleatoriedade

Você recebe capturas de memória RAM de três máquinas e deve encontrar o endereço da primeira instrução do kernel (função _stext) para cada uma delas.

O formato da flag é FCSC{phys-virt} onde:

- phys é o endereço físico da primeira instrução do kernel, - virt é o endereço virtual da primeira instrução do kernel na área de mapeamento de texto do kernel (kernel text mapping).

Todos os endereços são de 64 bits, em formato hexadecimal com prefixo 0x.

Por exemplo: FCSC{0x0123456789abcdef-0xfedcba9876543210}

Nota: Durante o FCSC, o número de tentativas foi limitado a 10 para este desafio.
